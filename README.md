# LXV Wine MCP server (public, read-only)

Public, read-only [Model Context Protocol](https://modelcontextprotocol.io) endpoint for LXV Wine (Paso Robles, CA).
It lets AI assistants read the wine catalog, events and visit information. It cannot place orders or make bookings.

- Endpoint (streamable HTTP): https://www.lxvwine.com/mcp
- Details: https://www.lxvwine.com/ai/
- Registry name: `com.lxvwine.www/public-read-only`

This repository holds the public description and registry manifest only. The server runs on lxvwine.com.
